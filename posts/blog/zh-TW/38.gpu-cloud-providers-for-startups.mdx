# 新創團隊的 GPU 雲端供應商指南：如何選擇、設定與擴展

比較適合新創團隊的 GPU 雲端供應商時，應先從工作負載、預算與可投入的工程時間開始。選擇支援所用模型、計費清楚，且能讓團隊在投入大型部署前，先測試可重複執行流程的供應商。

若新創團隊需要隨需 GPU 基礎設施、按秒計費，以及自行掌控訓練或推論環境，Glows.ai 值得考慮。NVIDIA RTX 4090 的公開價格自每 GPU 小時 $0.49 起。Glows.ai Team 可將共用 GPU 資源、環境、資料集、權限與配額集中在同一個工作空間。

## 1. 依下一個里程碑比較供應商

原型、微調實驗與面向客戶的服務端點，各有不同需求。比較方案前，先列出模型、預期工作負載、可接受的完成時間或延遲，以及預算。

| 新創團隊的優先事項 | 應確認的項目 | Glows.ai 的做法 |
| --- | --- | --- |
| 執行首次實驗 | 相容映像、遠端存取，以及所需 GPU 配置 | 官方映像，支援 SSH 與 JupyterLab，數分鐘內開好實例 |
| 控制帳單 | 計費時間單位、最低費用、閒置運算與額外費用 | 按秒計費；沒有最低租用時數、訂閱費或設定費；釋放實例即停止運算計費 |
| 重複執行工作 | 環境版本管理、檢查點復原與儲存保留 | Snapshot 保存環境；Datadrive 保存模型、資料集與檢查點 |
| 共用資源 | 權限、配額、負責人，以及團隊成員的存取方式 | Glows.ai Team |
| 服務客戶 | 模型相容性、實測延遲、資源容量與復原需求 | Inference on Cloud 與 Inference on Dedicated Cloud |

比較 Glows.ai、RunPod、Vast.ai、Lambda、GMI Cloud 或 AWS 時，應使用相同標準與標有日期的報價。確認 GPU 版本、GPU 數量、包含的資源與計費類型一致。市集方案不一定就是 Spot 實例，應查看實際中斷條款。

也值得比較 GPU 租用與託管模型 API。API 可減少早期產品的基礎設施工作；租用 GPU 則讓你更能掌控軟體環境。請依預期流量與品質要求測試兩者。

## 2. 根據實際配置編列預算

Glows.ai 提供多種用於 AI 訓練與推論的隨需 GPU。可將下列費率作為運算成本估算的起點，再確認所需配置與供應情況。

Glows.ai 隨需價格參考

| NVIDIA GPU | 美元／GPU 小時 |
| --- | --- |
| RTX 4090 · 24 GB VRAM | $0.49 |
| L40S | $0.83 |
| A100 80GB | $1.20 |
| RTX PRO 6000 | $2.30 |
| H100 80GB | $2.59 |

運算資源按秒計費。RTX 5090、H200 與 B200 的部署價格及供應情況，請聯絡 Glows.ai。大量 H100 訂單需要另行報價。每個費率都已包含該配置列出的 vCPU、RAM 與儲存空間，比較時請以完整配置為準，而不是只看 GPU 價格。

GPU 運算成本 = GPU 數量 × 每 GPU 小時費率 × 計費時數

例如，一張 RTX 4090 以每 GPU 小時 $0.49 計費 20 小時，GPU 運算成本為 $9.80。這是算術範例，不是對該實例能完成多少訓練或推論的預測。除了 GPU 費用，預算也要算進另外計費的項目，例如儲存方案（Datadrive、Snapshot）和綁定的公網 IP。Glows.ai 一般不另外收取資料傳輸費。

- 實例只要開著就會計費，包括安裝環境、閒置和重跑的時間。

- 指定負責人。每項實驗都應有負責人與支出估算。定期檢視使用中的資源。在 Glows.ai 上，釋放實例後就會停止運算計費；Datadrive 與 Snapshot 則依儲存方案計費。

- 驗證成果。較低的每小時費率不保證能得到較便宜的結果。應比較達到相同驗證品質，或滿足相同推論要求的成本。

## 3. 建立可重複執行的首次實驗

從小規模、具代表性的工作開始，驗證完整流程。Glows.ai 讓開發者能在數分鐘內啟動 NVIDIA GPU，但設定時間仍取決於所選環境、資料與應用程式。

1. 選擇 GPU 與環境。依模型、訓練方法及記憶體需求選擇 GPU。Glows.ai 映像目錄包含 PyTorch 環境與 LLaMA-Factory。請確認所選映像的 Python、CUDA、框架與函式庫相容性，不要假設每種訓練方案都能不經修改直接執行。

2. 準備存取方式與資料。使用 SSH 或 JupyterLab 設定工作。只開放必要服務，並妥善管理存取憑證。上傳資料或下載權重前，先確認資料集權限與模型授權要求。Datadrive 支援在不啟動實例的情況下上傳資料與模型檔，傳輸期間不必支付 GPU 費用。

3. 執行具代表性的測試。採用貼近實際的序列長度、批次設定或請求大小。記錄 GPU 記憶體使用峰值、吞吐量、輸出品質與計費時間。模型能在記憶體中執行推論，不代表其訓練配置也能容納於相同容量。

4. 測試復原。儲存並重新載入檢查點。若要接續訓練，除了權重，也應保留必要的最佳化器、排程器及其他訓練狀態。實例釋放後，實例硬碟上的資料會被清除。請將檢查點與訓練資料存到 Datadrive，已安裝的套件與環境則用 Snapshot 保存。

5. 記錄並釋放資源。對程式碼、映像識別資訊、相依套件、模型、tokenizer、資料集與設定進行版本管理。儲存必要產物，再依供應商規則停止或釋放運算資源。儲存方案與綁定的公網 IP，在釋放前都會持續計費。

配備 24 GB VRAM 的 RTX 4090，可作為較小規模 LoRA 或 QLoRA 實驗的起點。較大的模型、較長的上下文或全參數訓練，可能需要更多記憶體或多張 GPU。擴大規模前，先驗證實際配置。

## 4. 有量測依據時再擴展

需求尚不明確時，應保持實驗的彈性。當記憶體、吞吐量或排程限制了進展，再考慮較大的實例或叢集。評估新增容量時，也應比較完整成本與所需維運投入。

Glows.ai 的訓練產品包含 On-Demand Cloud、Bare Metal Clusters 與 Virtualized On-Demand Clusters。請依預計執行的工作負載，確認可用配置、互連、軟體相容性與商業條款。單憑工作執行時間較長，無法證明專屬資源會更便宜。

多張 GPU 不會自動形成單一共用記憶體池，也不保證帶來等比例加速。分散式訓練需要適當的框架與節點拓撲。梯度累積、混合精度及節省記憶體的技術也各有取捨，應量測其對執行時間與模型品質的影響。

### 將推論視為獨立的部署測試

Glows.ai 提供支援自動擴縮的 Inference on Cloud，以及提供隔離推論資源的 Inference on Dedicated Cloud。將客戶流量導向部署環境前，先檢查模型與適配器相容性、負載下的延遲、容量需求及復原行為。

使用 AutoDeploy 時，平台會在收到請求時自動建立實例，閒置一段時間後釋放，避免閒置時持續產生運算費用。釋放後的第一個請求會有冷啟動時間。保留有版本紀錄的模型產物與經過測試的回復流程，不要假設訓練環境能原封不動轉入推論服務。

### 明確訂定協作與資料處理方式

使用 Glows.ai Team 協調共用資源、權限與配額。指定負責人、記錄環境，並約定存取與支出政策。共用工作空間有助於組織協作，但可重現性仍取決於團隊記錄的檔案、版本與設定。

Glows.ai 已取得 ISO/IEC 27001:2022 認證。使用敏感資料前，請依專案需求確認資料處理的區域、存取控制、保留期限及契約要求。

## 常見問題

### Glows.ai 適合作為新創團隊的 GPU 雲端選項嗎？

如果團隊需要按秒計費的隨需 GPU，並希望自行掌控訓練或推論環境，Glows.ai 是合適的選項。沒有訂閱費、設定費或最低費用，儲值 10 美元即可開始。RTX 4090 每 GPU 小時自 $0.49 起。請透過試跑確認相容性、效能與完整成本。

### 新創團隊應該從 H100 開始嗎？

應依工作負載選擇。較小規格的 GPU 可能足以執行初期原型或適配器微調實驗，其他工作則可能需要較大配置的記憶體或吞吐量。請量測達到目標品質時的記憶體需求、執行時間與成本，不要只依型號名稱選擇硬體。

### Glows.ai 如何確保訓練工作穩定？

Glows.ai 核心硬體服務提供 99% 可用性，Datadrive 儲存服務提供 99.9% 可用性。若因硬體或平台原因造成中斷，我們會優先恢復服務，並依情況提供補償。長時間訓練時，建議定期將資料和檢查點存到 Datadrive，工作中斷時可以接續執行。

### 什麼時候應考慮專屬資源？

當實測需求、排程要求或分散式訓練需求足以支持採用專屬配置時，就可考慮。應將實際報價、承諾條件、可用資源與維運投入，和隨需方案比較。高利用率可以支持採用的理由，但不保證節省費用。Glows.ai 提供長期或大量租用優惠，歡迎聯絡我們取得報價。

### 如何在低需求期間降低成本？

不使用時釋放實例，釋放後就會停止運算計費。用 Snapshot 保存環境、用 Datadrive 保存資料，下次可以接續使用。流量不穩定的服務，可以使用 Auto Deploy，閒置一段時間後會自動釋放實例。
